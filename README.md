# APIs Divertidas

Aplicativo Flutter para explorar cães, Pokémon e personagens de Rick and Morty.

## Recursos

- **Galeria de cães:** sorteia fotos de vira-latas caramelo e outros cães, com perfis fictícios. As fotos selecionadas do Wikimedia Commons exibem créditos e licença no aplicativo.
- **Pokédex:** pesquisa Pokémon por nome ou número e apresenta uma coleção de destaques.
- **Personagens:** consulta e explora personagens de Rick and Morty.
- Interface responsiva para dispositivos móveis e telas maiores.

## Executar

Pré-requisitos: Flutter SDK compatível com `pubspec.yaml`.

```bash
flutter pub get
flutter run
```

## Testes

```bash
flutter test
flutter analyze
```
